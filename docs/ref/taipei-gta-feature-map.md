## 3. 分階段對齊建議

**階段 A — 操作與手感（先做，改動小、玩起來差最多）**
- 鍵位整批對齊（左鍵攻擊、E 互動、H 喇叭、V 鏡頭、C 回頭看、F 扶起車）
- 鏡頭：步行 4.1 m + 越肩 0.3、V 三段；駕駛三段 + 速度拉遠 + FOV 62→66；仰角收到 −35°；駕駛自動回正
- 角色：跑速 7.0、加速放慢、coyote / 跳躍緩衝
- 車輛極速上調、機車傾斜與倒地、喇叭
- 理由：全是既有模組的參數與小功能，S 級為主，立刻拉近手感

**階段 B — HUD、選單與存檔（讓遊戲有外殼）**
- 開始畫面、Esc 暫停選單（繼續 / 地圖 / 設定 / 操作說明 / 統計 / 回主選單）
- 設定頁：畫質五檔、三組音量、靈敏度滑桿、反轉 Y、提示開關
- HUD 重排：右上時間 / 溫度 / 金錢 / 武器，左下血條，右下時速圓錶 + 路牌，中下目標列與字幕
- 金錢 + localStorage 自動存檔 + 統計
- 觸控改版：搖桿推到底衝刺、駕駛踏板、左上三顆小鈕
- 理由：後面所有系統（任務、通緝）都需要這些顯示位置與存檔

**階段 C — 城市活起來（交通與 NPC）**
- 紅綠燈 + 倒數、停止線、行人燈
- 車流 8 → 50 台、行人 15 → 70～120（InstancedMesh + 遠近分級），機車佔約 4 成
- 行人逃跑、被撞反應；搶車（F 拖出司機）
- 車輛耐久與冒煙
- 理由：通緝與任務都依賴「有車可搶、有人會逃」

**階段 D — 系統（通緝、任務、地圖、手機）**
- 通緝 1～5 星、警車追捕、搜索圈、被捕 / 死亡流程與罰鍰
- 任務框架（光柱、目標列、字幕、結算）+ 3 個示範任務
- M 大地圖（圖例、點擊導航）+ 世界導航圖釘
- T 手機（任務 / 地圖 / 設定 App）
- 理由：核心玩法迴圈，前三階段打好地基後才好接

**階段 E — 氛圍與移動**
- 天氣（雨、濕地面、霧）+ HUD 天氣
- 音效（引擎、腳步、喇叭）+ 電台 2～3 台
- 捷運綠線快速移動（選站 → 淡出 → 到站）
- 武器：球棒 → 手槍；手把完整映射
- 理由：提升沉浸感，但不影響核心迴圈

**階段 F — 內容擴充**
- 更多車種（補齊 13 種）、角色選擇、收集品、支線與打工任務
- 區塊串流 + 擴區（中區 / 草悟道 / 逢甲夜市）、文化系統（夜市、廟宇、垃圾車）、諧仿招牌、拍照模式、多語系
- 理由：純內容量，依時間逐步追加
