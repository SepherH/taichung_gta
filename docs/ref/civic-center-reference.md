查證日期：2026-09-30（台灣時間）。可信度標記：**已確認** = 親眼在照片 / 衛星 3D / 官方文字看到；**OSM** = 取自 OSM 物件 tag 或節點座標（資料本身可信，但非親眼驗證現況）；**推測** = 由文字或間接推得；**估算** = 由 OSM 座標 / 截圖比例量出，會註明方法。

量測換算：1° 緯度 = 110,750 m、1° 經度 = 101,570 m（緯度 24.16°）。OSM 資料取自 `data/osm/qiqi-raw-v2.json`，尺寸為輪廓最小外接矩形（逐度旋轉求最小面積）。七期斜格網方位同 `tiger-city-reference.md`：長軸 **121°**（往東南）/ **31°**（往東北）。

## 1. 臺中市政府臺灣大道市政大樓（OSM way 222413435）

- **地址 / 基本資料**：西屯區臺灣大道三段 99 號；地上 10 層、地下 2 層；屋頂高 **43.2 m**；2007–2010 興建；設計 瑞士 Weber＋Hofer AG（韋伯/侯佛）。已確認（zh.wikipedia 資訊框，https://zh.wikipedia.org/zh-tw/臺灣大道市政大樓）
- **OSM tag**：`building:levels=10`、`building:levels:underground=2`、`bridge=yes`、`layer=1`（OSM）。`bridge=yes` 對應中央門洞上方的跨越段
- **佔地（OSM 輪廓）**：單一細長矩形，長 **253 m**（方位 121°，沿市政北X路方向）× 寬 **53 m**，面積約 13,200 m²；中心 24.161802, 120.646761（OSM）。四角約 24.16252,120.64591 / 24.16133,120.64804 / 24.16093,120.64777 / 24.16211,120.64564
- **量體組成**：**一整棟長條板樓 + 中央大門洞（門型）**，不是分開的兩棟塔樓，也沒有獨立空橋。維基文字：「建築中央下方簍空造型」，空間分為文心樓（東側）、中央川堂、惠中樓（西側）。已確認（官方式文字 + 空拍照 + Google 3D）
  - 門洞：由地面貫穿到中高樓層，上方數層樓連成一體跨過去（門楣）。門洞內有一個懸掛的灰色量體（推測為 4F 集會堂，維基：「集會堂，樓底有 4 層樓高」），朝廣場那面在部分照片是大型 LED 螢幕（照片看到黃色 / 影像畫面）。已確認（照片）
  - 門洞尺寸：寬約 **60–75 m**、淨高約 **25–28 m**（約 6 層），門楣厚約 15–18 m。估算（Google 3D 俯視：門洞暗區佔立面長度約 195/760 px × 253 m ≈ 65 m；空拍照門洞高度約佔立面高 60%，× 43.2 m）
- **屋頂**：**平屋頂**，淺灰色，兩翼大面積深色太陽能板；中央門楣上方有一個長方形**屋頂開口 / 天井**（有鋼構架橫跨，推測對應 9F 空中花園）；屋頂有數個白色機房小量體。已確認（Google 3D）
- **外牆 / 立面**：**藍灰色玻璃帷幕**全包，帶密集**水平條紋**（水平遮陽 / 層間帶）；立面上有數條**白色垂直核心筒**（小窗、實牆），夾在門洞兩側及兩翼。已確認（照片）。維基：「以玻璃帷幕包覆」
  - 主色：玻璃 **#4F6F8F**（藍灰，陽光下偏亮藍）、水平帶 **#A9B8C6**、白色核心筒 **#E3E3DE**、門洞內灰色量體 **#8C8F93**。估算（照片目視取色）
- **主入口朝向**：門洞與府前廣場朝 **東北**（面向臺灣大道）；背面朝西南接市政公園 / 府會園道。已確認（Google 3D + 維基照片說明「市政大樓背面與市政公園」）
- **前方廣場**：「臺中市政府前廣場」，**大面積淺灰石材鋪面廣場**（#CFCAC0，估算），中軸一條分隔線，旗桿群；兩側（西北、東南）是草坪 + 行道樹、地面停車場（維基：戶外停車場 256 車位）。未見水景。已確認（Google 3D + 照片）
  - 廣場縱深：建築東北立面到臺灣大道三段中心線 **183–226 m**（OSM 多條車道中心線）；廣場東側有新光人壽大樓、林皇宮等其他建物佔據一角，不是整片空地。估算 / 已確認（Google 3D）
- **招牌 / 文字**：①廣場北側地面有白色石材銘牌，刻「臺中市政府 / TAICHUNG CITY GOVERNMENT」（維基照片說明）；②門洞入口雨遮底面有「臺中市政府」字樣（照片）。已確認
- **周邊道路**：西北 惠中路、東南 文心路二段（在建築東南端外約 50 m）、東北 臺灣大道三段、西南 府會園道。已確認（OSM + 維基「週邊道路」）
- 來源：https://zh.wikipedia.org/zh-tw/臺灣大道市政大樓 ；Google 地圖 3D（24.1618,120.6468 一帶）；Google 圖片搜尋照片（台中都市資訊站、臺中觀光旅遊網等）；https://www.openstreetmap.org/way/222413435

## 2. 臺中市議會 議政大樓（OSM way 222636758）

- **地址 / 基本資料**：西屯區市政北一路 56 號；地上 14 層、地下 1 層、鋼骨構造、**總高度 69.8 m**、總樓地板 43,277 m²。已確認（臺中市政府全球資訊網 2010-05-14 新聞稿，Google 搜尋摘要文字）。另有部落格寫「規劃高度約 66 m」（較早版本），以官方 69.8 m 為準
- 設計同為 Weber＋Hofer，劉培森建築師事務所協同；2012-12-24 遷入。已確認（zh.wikipedia 臺中市議會；劉培森事務所網站摘要）
- **樓層用途**：14F 辦公 / 資訊機房 / 圖書室 / 餐廳，9–13F 議員研究室，8F 議事大廳，6–7F 首長辦公區，2–5F 市民集會堂。已確認（劉培森事務所網站摘要）
- **佔地（OSM 輪廓）**：矩形 **108 m**（方位 122°，與市政府平行）× **32 m**，面積約 3,400 m²；中心 24.158608, 120.644687（OSM）
- **量體形狀**：**方正的單一板塊**，從公園側看立面寬高比約 1.5（108 × 70 m），像一個扁的玻璃方盒。已確認（Google 3D + 照片）
  - **上方穿透開口**：立面中上部有一個大型長方形開口，貫穿前後（3D 可看穿到後方建物），**下緣是往下彎的弧形**；位置略偏西北端。寬約 30 m、高約 15 m。已確認（形狀）/ 估算（尺寸，3D 截圖比例）
  - **底部開口**：地面層中央有寬大的通透開口（寬約 60 m、高約 10–12 m）。推測 + 估算（Google 3D mesh 呈現為可看穿的空洞，但 mesh 品質低，照片中底部被樹遮住，未能確認細節）
- **外牆 / 立面**：全面**鏡面藍色玻璃帷幕**，帶細密水平條紋，反射天空與周邊高樓；開口內側為淺色弧面。主色 **#5D7FA3**（估算）。已確認（照片）
- **屋頂**：平屋頂，淺灰；維基提到「頂樓空中花園」。已確認（3D 平頂）/ 空中花園細節查無
- **與市政府的關係**：議會在市政府**西南方約 410 m**（中心相對位移 西 200 m、南 357 m），兩者之間是**市政公園 + 新市政公園**（府會園道圍成的長條綠地，中央有圓形下沉水景 / 地下停車場天井，公園下為地下停車場）。**沒有空橋或地面連廊**，是隔著公園軸線遙對。已確認（Google 3D 兩個方向目視）
- 議會面向公園（東北）那面是主視覺立面；議會前（東北側）有一塊方形草坪庭院。已確認（照片 + 3D）
- 來源：https://zh.wikipedia.org/zh-tw/臺中市議會 ；https://www.taichung.gov.tw（2010-05-14 市政新聞，經 Google 搜尋摘要）；http://www.rickyliu.com.tw（project 頁摘要）；Google 地圖 3D；Google 圖片搜尋照片；https://www.openstreetmap.org/way/222636758

## 3. 捷運市政府站（綠線高架站；OSM way 862750722 / 431599603 / 223060696）

- **基本資料**：臺中捷運綠線 110 站（藍線 214 站興建中，地下）；文心路二段 688 / 699 號；綠線**高架車站、側式月台**；樓層：1F 出入口、2F 樓梯轉接層、**3F 穿堂 + 月台**、**4F 月台連絡天橋**；兩個出入口均設在文心路東西兩側的**聯開共構大樓**內。2021-04-25 通車。已確認（https://zh.wikipedia.org/zh-tw/市政府站_(臺中市)）
- **站體（OSM 862750722，layer=3）**：長 **125 m**（方位 31°，沿文心路）× 寬 **28 m**，中心 24.161753, 120.648969，坐落在文心路二段正上方，南端距臺灣大道口約 40–60 m（OSM）
- **出入口 / 聯開基地（OSM 431599603、223060696）**：兩塊都標 `building=train_station`
  - 431599603：文心路**西側**、臺灣大道南側，84 × 52 m，中心 24.162173,120.648593 → 對應 G9-1（出口 1 側）。Google 3D（2026 影像）是**開挖中的工地**，地圖標「冠德環球購物中心（興建至 2029 年）」，規劃地上 43 層、高 208 m。已確認（3D + 維基）
  - 223060696：文心路**東側**，85 × 53 m，中心 24.161719,120.649621 → 對應 G9-2（出口 2 側，富王大飯店旁）；3D 同樣是施工基地。已確認（3D）
- **外觀**：**方盒形站體**，不是其他綠線站那種波浪曲面殼頂。立面是**灰色金屬水平百葉 / 金屬板**，頂部平屋頂，淺灰色、有數條長條形天窗。已確認（Google 3D）
  - 軌道進站前兩端有**半圓拱形全罩式隔音罩**（綠色半透明面板 + 肋條）接進站體端部開口。已確認（Google 3D）
  - 主色：金屬立面 **#9EA3A8**、屋頂 **#CFD1D2**、隔音罩 **#8CC5B4**（半透明綠）、橋墩混凝土 **#BFBDB8**。估算（3D 目視取色）
- **高度**：月台在 3 樓，屋頂在 4F 天橋之上。站體底面離路面約 8–10 m、屋頂約 **22–25 m**。估算（依 4 層樓 × 約 5.5 m；3D 目視站體高於兩側 3 層老建物）。官方數字查無
- **橋墩**：站體外的高架軌道是單柱混凝土墩立在文心路中央分隔島上（3D 看到淺色墩柱）；站體正下方的墩柱數量與位置查無（3D mesh 太糊，無可用街景）
- **與臺灣大道的關係**：綠線沿文心路南北向高架，站體在文心路 × 臺灣大道路口**西南方**，南端貼近路口；藍線將在臺灣大道三段**地下**交會（興建中）。站體中心距市政府東南端約 50 m、距市政府中心約 230 m（往東）。已確認（維基 + OSM）
- 來源：https://zh.wikipedia.org/zh-tw/市政府站_(臺中市) ；Google 地圖 3D（24.1618,120.6490 一帶）；https://www.openstreetmap.org/way/862750722 、/way/431599603 、/way/223060696
