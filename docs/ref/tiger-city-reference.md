# 老虎城（Tiger City）與周邊實景建模參考

查證日期：2026-09-30（台灣時間）。可信度標記：**已確認** = 親眼在 OSM 圖資 / 衛星 3D / 街景上看到；**OSM** = 取自 OSM 物件 tag 或節點座標（資料本身可信，但非親眼驗證現況）；**推測** = 由文字或間接推得；**估算** = 由地圖比例尺 / 截圖量出，會註明方法。

## 0. 座標系（建議建模直接採用）

七期街道是**斜格網**：河南路 / 惠來路 / 朝富路 走向方位角約 **31°**（往東北），市政北X路 / 市政路走向約 **121°**（往東南）。本文件所有相對位置用下列局部座標（公尺）：

- 原點 O = 老虎城 OSM 輪廓中心 **24.16435, 120.63790**
- **a 軸** = 沿河南路往東北（bearing 31°）為正；**b 軸** = 沿市政北六路往東南（bearing 121°）為正
- 換算：x東 = b·cos31° + a·sin31°、y北 = −b·sin31° + a·cos31°；1° 緯度 = 110,750 m、1° 經度 = 101,570 m（緯度 24.16°）
- 建議 three.js：`X = b`、`Z = −a`（北東向為 −Z），整個世界就能保持道路軸對齊，只要在小地圖 / 羅盤上轉 31°
- 驗證：河南路 OSM 兩條單向車道中心線 b = 69 與 79、市政北六路 OSM 中心線 a = 119–129，確認格網方位誤差 < 1°（OSM way 617310344 / 1049620878 / 24296703 / 1050553594）

## 1. 老虎城本體

- **地址 / 臨路**：臺中市西屯區河南路三段 120 號（OSM way 150999799、維基百科）。所在街廓 = **河南路三段（東南側）、市政北六路（東北側）、朝富路（西北側）、市政北二路（西南側）**。已確認（OSM 地圖，https://www.openstreetmap.org/way/150999799）
- **樓層**：地上 7 層、地下 3 層（OSM `building:levels=7`、`building:levels:underground=3`；zh.wikipedia 同）。4F–7F 威秀影城、3F 戶外運動、2F 時尚、1F 國際名品、B1 親子生活（唐吉訶德）、B2 主題娛樂、B3 停車場（zh.wikipedia）
- **高度**：查無官方數字。推測約 **35–40 m**（7 層，含影城挑高樓層；Google 3D 目視明顯低於周邊 20–40 層住宅 / 商辦塔樓）
- **佔地形狀（OSM 輪廓，已確認為 OSM 資料）**：**L 形**，外包矩形 b −35…+43（約 **78 m**，沿市政北六路方向）× a −37…+43（約 **80 m**，沿河南路方向），缺角在東側象限（b −4…+43、a +3…+43，約 47 × 40 m），缺角朝向河南路 × 市政北六路路口。頂點（lat,lon）：24.16484,120.63781 / 24.16422,120.63743 / 24.16388,120.63809 / 24.16419,120.63828 / 24.16439,120.63788 / 24.16471,120.63808
  - 注意：Google 3D（2026）目視量體比 OSM 輪廓完整，缺角處其實是**前廣場 + 下沉廣場**與立面塔樓，所以 L 形的缺角可理解為「戶外廣場」
  - 建築外牆距河南路中心線約 30 m（a 軸方向為 b 43 → 74）；北側與市政北六路之間隔著朝富停車場與林酒店，不直接臨市政北六路
- **主立面與入口**：主立面**朝東南，面向河南路三段**。已確認（Google 街景 2024-12，河南路三段 120 號前）
  - 左（西南）量體：銀灰金屬板立面，頂角有大型「**TIGER CITY**」招牌 = 深藍色同心漩渦圓形 logo + 其下深灰金屬字；底層 ZARA 店招（立面上另有 ZARA 字樣）
  - 1F 白色圓柱騎樓 / 柱廊，2F 外露陽台（玻璃欄杆 + 綠色植栽槽）與外部樓梯
  - 中央：大片鋪面前廣場（灰 / 米色方磚，嵌小塊人工草皮），往內接中庭與**下沉廣場**（寬大階梯下到 B1、木平台、戶外咖啡座、球形橘黃燈柱與咖啡色指標牌）；中庭內側立面可見 VOUX、GUESS 等店招。已確認（街景 + Wikimedia Commons「Tiger City Sunken Plaza 2019.jpg」）
  - 右（東北）側：**玻璃電梯 / 景觀塔**（灰框玻璃帷幕，高度目視約 9–10 層，高出主體）；其前方為**圓柱形綠牆亭**（原臺灣首座自行車機械停車塔，2009 啟用，現拆除設備改街邊店；外覆藤蔓，頂為圓盤平頂）。已確認（Google 3D + 街景；沿革見 zh.wikipedia）
- **屋頂**：大致平頂、淺灰；後段（西北）是最高的白色大方盒（影城），頂有機電設備；左前量體屋頂有**屋頂花園 + 玻璃圓筒中庭（rotunda）**與一個淺綠金字塔形採光頂。已確認（Google 3D 衛星）
- **停車**：地下停車場入口標示「老虎城地下停車場」在建物東側近河南路（Google 3D 標籤，位置推測）；北側為大型平面「朝富停車場」。已確認（OSM + Google 3D）
- **夜間燈光**：查無（僅 zh.wikipedia 有夜景照片標題，未取得內容描述）。推測可做：TIGER CITY logo 背光、玻璃塔樓內透光、廣場球燈
- 建築師：倉持光男（日本）負責整體空間與景觀規劃；2002-01 開業（zh.wikipedia）

## 3. 周邊建築與地標

**同街廓（緊鄰老虎城）**
- **林酒店 The Lin Hotel**：老虎城西北後方，靠朝富路 / 市政北六路側（OSM 地圖標 zoom18 位置約 24.1652,120.6374，估）。超高層塔樓，深古銅 / 棕色玻璃帷幕 + 規律白色水平帶，頂部弧形收頭；裙樓屋頂有泳池。樓層數查無（目視遠高於老虎城，推測 30 層以上）。已確認外觀（Google 3D）

- **興富發「鼎盛 BHW」商辦**：老虎城西南側（OSM 標「興富發鼎盛大廈」約 24.1637,120.6377）。老虎城原二期用地改建（zh.wikipedia）。深藍灰玻璃超高層辦公塔，帶垂直鰭片與退縮。樓層查無。外觀已確認（Google 3D），位置 OSM

- **農田水利署台中管理處**：同街廓西南角大片低矮建物 / 空地（OSM 地圖）。細節查無

## 4. 街景質感（讓場景像七期）

- **河南路**：每向 2 車道，中央分隔綠帶約 4–6 m（估），內種修剪整齊的低矮灌木帶 + 一排落葉喬木；樹種查無（目視葉色轉黃、樹形散開，推測台灣欒樹或楓香類，標推測）。已確認（街景 2025-10）
- **路緣**：外側車道邊**紅線**（禁停）、部分黃線；路面白色「河南路三段」地面字、公車停靠區白色「公車」框線字。已確認（街景）
- **人行道**：寬（估 5–8 m），灰色大方磚鋪面，局部紅磚色帶；廣場前為灰 / 米色方磚、嵌小塊人工草皮。已確認
- **路燈**：灰色單臂高燈桿（立於中央分隔帶與路側）；廣場內為球形橘黃燈 + 咖啡色路標柱。已確認
- **公車站**：老虎城周邊 OSM 有 4 個公車站牌（河南路兩側、市政北六路兩側，例 24.16411,120.63838 / 24.16547,120.63818 / 24.16462,120.63957 / 24.16550,120.63957）。站體樣式查無
- **YouBike 2.0 站**：河南路東側人行道上一排橘黃色公共自行車；另有橘色短柱 + 鍊條隔離。已確認
- **標誌**：藍底白字「P」停車指引牌、限速 20 圓牌（進停車場處）。已確認
- **機車停車格**：本次街景未看到清楚的機車格，查無
- **帶狀綠地**：市政北六路沿線上方為惠來溪涵管，OSM 地圖可見一條沿路延伸的綠帶 / 步道（已確認於 OSM 地圖；實景未看）
- **天際線**：老虎城是低矮量體，四周被 20–40 層米色石材豪宅與深色玻璃商辦包圍 —— 這個「低矮商場被高塔環繞」的對比是七期的核心辨識點

## 6. 秋紅谷與地形（2026-09-30 補查）

### 6.1 基本數字
- 面積 **3 公頃（30,000 m²）**；2012 年啟用；原為會展中心 BOT 案開挖後停工留下的大型基坑，改建為**滯洪池公園**，回填土方用大里溪疏濬土。來源：https://zh.wikipedia.org/zh-tw/秋紅谷廣場 、https://travel.taichung.gov.tw/zh-tw/attractions/intro/818 （已確認文字）
