## 畫風指引

1. 美式漫畫 / GTA 封面風：粗黑描邊、高對比平塗色塊，避免寫實攝影質感。
2. 主色：橘（#F07A1A 附近）＋紫（#4A2A6A 附近）晚霞，黑作為描邊與條紋色。
3. 提示詞固定尾綴：「美式漫畫風格，粗黑描邊，高對比平塗色塊，橘色與紫色晚霞色調，GTA遊戲封面插畫風格，畫面中沒有任何文字、字母或商標」。
4. 畫面內不放任何文字 / 品牌 / 車牌；看板題材「滿版、無邊框、無支架」，文字由程式疊。
5. 尺寸：橫式看板 1280x640（2:1）、直式 640x1280（1:2）、方形 1024；模板 qwen21，一張約 50 秒。

## 給程式端的接法建議

- cover.jpg：載入畫面全螢幕 `background-size: cover`，遊戲標題文字以 HTML/CSS 疊上。
- billboard-*.jpg：`TextureLoader` 載入後設 `colorSpace = SRGBColorSpace`，貼在 2:1 / 1:2 平面；需要店名時另用 CanvasTexture 疊一層文字帶，或在 canvas 上先 drawImage 再寫字。
- tiger-facade.jpg：貼老虎城正立面主牆（MeshBasic 或低 roughness）；側牆可用同圖 `repeat` 只取條紋區（UV offset 避開老虎頭）。
- logo-mark.jpg：縮成 32/180 px 作 favicon 與 apple-touch-icon；UI 小圖示可圓形遮罩。
- sky-dusk.jpg：作 `scene.background` 的等距柱狀貼圖（`EquirectangularReflectionMapping`）或大圓柱內側遠景，山線對齊地平線。
